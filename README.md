# OneArc Residence

Private luxury real-estate landing page built with the Sites Vinext starter, TypeScript, Tailwind CSS, GSAP, and Lenis.

## Commands

- `npm run dev` — local development
- `npm run build` — production build
- `npm run lint` — static checks

Project intent, scope, and acceptance criteria live in [PROJECT.md](./PROJECT.md). Work status lives in [PROGRESS.md](./PROGRESS.md).
