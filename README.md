# Ramada Builders Ltd.

Ramada Builders real-estate landing page built with the Sites Vinext starter, TypeScript, Tailwind CSS, GSAP, and Lenis.

## Commands

- `npm run dev` — local development
- `npm run build` — private Sites/Vinext build
- `npm run build:cloudflare` — static Cloudflare production build
- `npm run build:pages` — legacy GitHub Pages static build
- `npm run lint` — static checks
